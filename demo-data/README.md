# KathaGraph demo archive

Files for the hackathon demo, uploaded through the site so the real pipeline (EXIF/GPS, OCR, embeddings, claim extraction) processes them.

**Field notes marked "DEMO FIELD NOTE" were written by the team from public sources.** They are not original site visits.
Two notes per monument deliberately record a detail that sources genuinely disagree on, so the conflict view has real material to show:

- **Adalaj Stepwell:** construction year 1498 vs 1499 (the inscription is dated Samvat 1555, which converts to 1498 or 1499 depending on the calendar used).
- **Rani ki Vav:** completed by Queen Udayamati around 1063 as a memorial (the account traced to the Prabandha Chintamani) vs started around 1050 under King Bhima I (as told in popular accounts online).

## Rules for photos

- Download the **original file** from Wikimedia Commons (resized copies lose the GPS). Only use a smaller size if the original is over 20 MB.
- Put the monument name in every file name, e.g. `adalaj_stepwell_interior.jpg`, `rani_ki_vav_exterior.jpg`. Photos without GPS are linked to their monument by name.
- One Adalaj interior photo is kept out of this folder on purpose: it is uploaded live in the demo video, so the "interior photo missing" gap visibly gets ticked off.
